# Sakreen Shot — UX Mockup Refinement Prompt v1

**Recommended file name:** `sakreen-shot-ux-refinement-round-01.md`

## Purpose

Use the attached four-screen Sakreen Shot concept as the exact visual base. Do not redesign the product from scratch. Refine the existing concept carefully so it becomes a production-quality Android UX reference.

The visual direction is already approved:

- premium beige and parchment palette
- warm ivory surfaces
- deep espresso text
- restrained bronze accents
- luxury editorial feeling
- quiet, private, trustworthy atmosphere
- no neon colors
- no cyberpunk styling
- no generic SaaS appearance

The goal of this round is to improve clarity, accessibility, hierarchy, consistency, and Android realism while preserving the approved identity.

# REFINEMENT TARGETS — 10 OUT OF 10

## 1. Paper Texture — Refine to 10/10

Reduce the visible paper grain by approximately 35%.

The interface should feel inspired by premium paper, but it must not look aged, dirty, rustic, or heavily textured.

Requirements:

- keep the warm parchment character
- make the texture almost invisible behind small text
- use slightly more texture on large empty background areas
- use much less texture inside dense cards
- avoid stains, wrinkles, torn edges, or vintage newspaper effects
- maintain a clean modern luxury finish

Desired result:

A refined paper-inspired digital surface, not an old document.

---

## 2. Contrast and Readability — Refine to 10/10

Increase the functional contrast slightly while preserving softness.

Improve:

- secondary text readability
- card outlines
- inactive navigation labels
- filter-chip text
- small metadata
- category labels
- unselected circles and controls
- small icons

Requirements:

- primary text should remain deep espresso
- secondary text should be darker and easier to read
- borders should be slightly clearer
- selected states should be obvious
- no harsh pure black
- no bright white surfaces
- no heavy shadows

The interface must remain readable outdoors and on mid-range Android phone displays.

---

## 3. Typography System — Refine to 10/10

Create a more disciplined typography hierarchy.

Use:

- elegant serif only for the Sakreen Shot wordmark, major screen titles, and selected section headings
- modern sans-serif for all functional UI text
- monospace only for transaction IDs, reference numbers, and similar structured codes

Avoid using serif text excessively inside dense cards.

Improve:

- font-size consistency
- line-height
- text alignment
- spacing between title, subtitle, metadata, and action labels
- visual distinction between headings and functional information

Typography should feel premium, modern, and easy to scan.

---

## 4. Icon System — Refine to 10/10

Modernize and unify the icon family.

Use:

- thin, precise line icons
- consistent stroke width
- consistent visual weight
- simple geometric forms
- slightly architectural styling
- clean Android-friendly proportions

Refine icons that currently feel too decorative or vintage, especially:

- filing cabinet
- broom
- document folder
- storage imagery

Do not use:

- emoji-style icons
- cartoon icons
- ornate icons
- overly detailed illustrations
- glossy 3D symbols
- gold foil effects

The icons should feel custom, calm, and contemporary.

---

## 5. Archive Home — Refine to 10/10

Preserve the current layout because it is already strong.

Improve:

- spacing between the search bar and category grid
- card alignment and equal dimensions
- consistency of icon placement
- category title hierarchy
- item-count readability
- separation between Pinned Records and Storage Sanity
- bottom navigation clarity

Category cards should feel premium but functional.

The four categories must remain:

- Payments & Receipts
- Work & Chats
- Documents & Details
- Unsorted

Storage Sanity should retain its visual importance without becoming oversized or promotional.

Use the supporting subtitle:

“Review and remove old screenshots”

This subtitle should improve comprehension without weakening the branded feature name.

---

## 6. Intelligent Search — Refine to 10/10

Make matching information easier to scan.

The entered search query remains:

“Meezan 85000”

Keep filter chips:

- All
- Payments
- Chats
- Documents
- Pinned
- Recent

Improve the result-card hierarchy.

Each card should visually prioritize content in this order:

1. source or title
2. matched text
3. transaction or reference detail
4. category and date metadata
5. secondary actions

Example hierarchy:

Meezan Bank

PKR 85,000 sent successfully  
Transaction ID: 928374629

Payments & Receipts · 12 Jul 2026

Requirements:

- matching text should be highlighted in soft sand or muted bronze
- no fluorescent highlight color
- keep cards dense and compact
- do not enlarge cards unnecessarily
- align thumbnails consistently
- avoid tiny unreadable metadata
- keep pin and overflow controls subtle but clear

Search must feel fast, practical, and business-oriented.

---

## 7. Private Record View — Refine to 10/10

Create clearer visual separation between:

- the screenshot image
- extracted OCR text
- metadata
- user actions

Screenshot preview:

- place it on a slightly darker or more defined surround
- keep it visually separate from the OCR text section
- preserve realistic payment receipt content
- do not use real bank branding

Extracted Text section:

- use a cleaner, flatter reading surface
- improve text spacing and readability
- keep transaction IDs in monospace
- avoid making it look like another screenshot

Metadata:

- make rows compact and aligned
- use subtle dividers
- ensure category, captured time, indexing status, and expiry are easy to scan

Actions:

- Copy Text
- Share
- Change Category
- Delete

Delete should remain muted terracotta.

Keep the privacy line:

“Processed privately on this device”

This message should remain visible but understated.

## 9. Android Realism and Accessibility — Refine to 10/10

Make all four screens look like a real production Android app.

Requirements:

- realistic Android status bar spacing
- consistent system inset handling
- comfortable touch targets
- minimum practical tap areas
- balanced bottom-navigation height
- believable phone density
- no website-style layout
- no iOS-only patterns
- no inaccessible microtext
- no excessively thin controls
- no decorative elements that interfere with function

Ensure:

- category and search cards fit within realistic Android dimensions
- bottom navigation is identical across applicable screens
- top bars use consistent alignment
- back buttons, settings, pin, and overflow icons follow one system
- all screens feel part of one design system
