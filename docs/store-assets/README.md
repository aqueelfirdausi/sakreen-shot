## Compliance & Security Standard
- **100% Fictional Test Data**: All screenshots captured for Play Store submission utilize strictly synthetic, non-sensitive QA data.
- **Zero Real Data**: No real customer names, CNICs, phone numbers, bank accounts, or private WhatsApp chats are used.
- **Native Android Resolution**: Captured in 1080 × 2400 (or native device aspect ratio) on physical test hardware with clean status bar.
